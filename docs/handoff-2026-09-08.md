## Gotchas

- **`--case-timeout 3600` is not optional** for this case. The flow is ~83
  steps and the 20-minute default seals it `blocked` mid-run with no verdict.
- **`codex-cli` is unreliable on this machine.** 19 provider failures in one
  run, `ERROR codex_models_manager::cache`, and `which -a codex` shows a
  `cmux-cli-shims` binary ahead of `~/.local/bin/codex`. Clearing the cache
  fixes it until the shim rebuilds it. `--repair` re-enters the generator role
  dozens of times, so a flaky provider there loses the whole case — the last
  good run had `--repair` off.
- **gemini-3.8-flash cannot author.** It returns "completed without a result
  event" on the ~18k-token authoring prompt. It is excellent for every small
  in-run call (agent 37 s a case against 403 s on claude sonnet). Its model id
  needs an explicit per-role `_EFFORT`; the repo's default
  `gemini-3.8-flash-medium` conflicts with `effort=low` and breaks four of five
  roles. Run `wowlidator doctor` before trusting any routing.
- **An authored flow survives `--resume`** and is the expensive part. It lives
  at `.wowlidator/reports/humi-en-login/e2e-01/hir-ec-001-key-in-60.flow.json`;
  delete it to force re-authoring.
- **The harness's Chrome pool leaks.** Every run that is cut short leaves its
  Chrome behind; 43 accumulated today and the OS killed a run for memory.
- **`docs/` is outside the sparse-checkout cone.** `mkdir -p docs` then
  `git add --sparse docs/<file>` to commit anything here.
